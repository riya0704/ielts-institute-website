# IELTS Institute Website

This project is a modern and professional-looking homepage for a fictional IELTS institute, built with React and Tailwind CSS.

## Design Choices

The design aims for a clean, modern, and professional aesthetic to build trust and credibility with potential students.

*   **Color Scheme**: A primary color of blue is used to evoke a sense of trust, intelligence, and professionalism. This is complemented by a neutral palette of grays for text and backgrounds to ensure readability and a clean look.
*   **Typography**: The font choice is clean and easy to read, with clear hierarchies for headings and body text to guide the user's attention.
*   **Layout**: The layout is spacious and uses a single-column flow for most sections, making it easy to scan and digest the information. The use of cards for features and testimonials helps to organize content in a visually appealing way.
*   **Responsiveness**: The design is fully responsive and works well on both desktop and mobile devices. Tailwind CSS's responsive utilities were used to ensure a seamless experience across different screen sizes.

## Interactive Features

To enhance the user experience, several interactive elements have been added:

*   **Smooth Mobile Menu:** The mobile navigation menu now has a smooth open and close transition.
*   **Hover Effects:** The feature and testimonial cards have subtle hover effects, making them feel more dynamic and responsive to user interaction.
*   **Fade-in Animations:** The testimonials fade in as the user scrolls down the page, thanks to the `react-intersection-observer` library. This adds a touch of elegance and draws attention to the content.
*   **Pulsing CTA Button:** The primary call-to-action button in the hero section has a subtle pulse animation to encourage user engagement.

## Setup and Installation

To get the project up and running on your local machine, follow these simple steps.

### Prerequisites

You need to have [Node.js](https://nodejs.org/) and [npm](https://www.npmjs.com/) installed on your computer.

### Installation

1.  **Navigate to the project directory:**
    ```bash
    cd ielts-institute-website
    ```

2.  **Install the dependencies:**
    ```bash
    npm install
    ```

### Running the Application

To start the development server, run the following command:

```bash
npm start
```

This will open the app in your default browser at `http://localhost:3000`.

### Building for Production

To create a production-ready build of the app, run:

```bash
npm run build
```

This will create a `build` folder with the optimized and minified files.# ielts-institute-website
